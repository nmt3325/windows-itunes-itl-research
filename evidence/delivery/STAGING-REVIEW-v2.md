# Sanitized evidence supplement v2

This is a staging proposal for owner review, not a publication or native certification.

- The 35 requested supporting paths are represented, with explicit scoped projections where necessary.
- Original 51 ASM files plus completed static phase3/phase4 C/ASM and replay source are included.
- Ten accepted historical candidate inputs and one retained failure are byte-pinned. Their 20 completed save-cycle hash/exit/oracle chains were rechecked offline.
- The selected inflate and deflate traces were recomputed offline against the approved synthetic ITLs. Only matched events/blobs are supplied.
- Three completed independent synthetic donor snapshots support the later static census; this is not cross-library merge acceptance.
- proposals/ contains a strict exact-set/casefold verifier proposal with nine passing stdlib tests. Production is unchanged.

## Provenance and safe interpretation

HASH-PROVENANCE-v2.json maps original SHA-256, staged SHA-256, target path and every transformation. ITL and bin data are byte-for-byte unchanged. Text uses LF and the generic WINDOWS_RESEARCH_RUN token. Original embedded hashes continue to identify the originals, not transformed text.

The single scope disclaimer in the census helper and its result was safely generalized; computation and the 52 pinned result rows were not changed. The later input manifest removes private-source metadata rows. A separate matched-only correlation projection excludes unrelated process streams.

The scan found only known nonpersonal default hosted-runner account paths within some hash-pinned synthetic binary payloads. Those binary paths were not redacted because that would invalidate the evidence; the exceptions are explicit in CLOSURE-SUMMARY-v2.json and require the owner's review. No private original inputs, audio/artwork, executable tools, credentials, runtime bundles or operational transcripts are included.

## Limits and integration

This overlay depends on the previously supplied synthetic fixtures/oracles. Historical path strings are not native portability guarantees. Do not point native scripts at a live or personal library. The owner must supply a disposable replay layout and externally pinned official tools/binary, check the proposed mappings, merge only approved files and regenerate the delivery manifest. Cached projects are deliberately not included.

No new native execution, static decompilation or original-instruction emulation was performed by this staging task. Read the remaining gaps in CLOSURE-SUMMARY-v2.json before making reproduction claims.
