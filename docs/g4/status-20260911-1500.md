## Corrections carried into this checkpoint

- A reported runner state of `ready` is not a liveness test. One Windows runner
  reported `ready` with thousands of seconds of TTL left while every command
  stayed queued and never started. Only the time since the runner was last seen
  exposed it. A command that never starts, plus a large last-seen age, means the
  runner is gone whatever the reported state says.
- A successful workflow run is not a successful publication. Confirm every push
  with `git ls-remote` against the branch.
- PowerShell `-replace` is case-insensitive. Substituting an upper-case
  placeholder also rewrote an identically named lower-case variable inside the
  payload and produced a syntax error before anything was written. Generated
  bodies now live in their own file and are read by the tool that consumes them.
  `-creplace` is the case-sensitive alternative.
- Line counts differ by counting method. `docs/g4/native-experiments.md` at this
  tip is 591 lines by `splitlines()` and 592 by splitting on the newline
  character, because the file ends with a newline; it is 35061 bytes. State the
  method, or state the byte count.
- A local record ID is not lineage. The COM interface reports a per-load index,
  and EXP-06 observed the library renumbering a restored track while its
  persistent ID survived.
